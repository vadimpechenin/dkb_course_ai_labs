Запуск через poetry
1. Перейдите в папку проекта и настройте окружение
Убедитесь, что Poetry будет создавать виртуальное окружение прямо внутри папки этого проекта:
bash
>>cd имя_скачанного_проекта
poetry config virtualenvs.in-project true

2. Установите все зависимости
Запустите команду установки. Poetry автоматически прочитает файл pyproject.toml (и файл poetry.lock, если он есть) и создаст изолированное окружение со всеми нужными библиотеками:
bash
>>poetry install
